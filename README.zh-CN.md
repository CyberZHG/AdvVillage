# 冒险者之村

[English](README.md) | 中文

**在线游玩：** https://cyberzhg.github.io/AdvVillage/

一款致敬开罗游戏的像素风模拟经营游戏。你负责铺路和建造，冒险者、采集者、村民和游客会自己生活，挂机也能一直运转。

- **建设村庄**：住房、商店、饭店、酒馆、洗浴中心、剧场、竞技场等，建筑门口朝向道路；特定建筑相邻可形成组合，提升收入与吸引力。路灯、长椅、池塘、风车、钟楼等装饰物还能带动周边店铺的生意。
- **特色商品**：店铺会把怪物素材和采集所得做成特色商品（蜂蜜面包、药草茶、珍珠纪念品等），以更高的价格售出。
- **冒险者**：八种职业，自动狩猎、接取讨伐委托、购买装备、锻造武器防具和饰品，还会获得称号、在 Lv.100 晋升为高级职业、结识劲敌、结为搭档、结婚生子。可以用镜头跟随任何一人，查看他们的个人经历。
- **100 种怪物**：分布在各村野外和十处远征地点，另有稀有的闪光个体，以及需要全协会合力讨伐的头目。野外的怪物会随村子一起变强，远征地可以一层层往深处推进；被击败的怪物偶尔会跟着冒险者回村，成为伙伴。
- **公会猫团子**：在门口打盹、跟着村民散步，好感度越高越亲近村子，会叼来小礼物，还会给它坐着的店铺带来好运。
- **研究**：用金币和材料换取永久提升；部分店铺在当季会更受欢迎。
- **游客**：观光消费，常客熟悉村子后会送来礼物。
- **季度委托**：每个季节给出几项目标；村子的**名声**不断积累，会吸引美食评论家、远方商队、王族视察、名匠、贤者和流浪英雄来访。
- **四季、天气与节日**：改变风景与客流；随机事件与行商让村子更有生气，且不会打断游戏。
- **评价**：第 16 年结束时评分并解锁下一座村庄（共五座，各有特色），之后可继续游玩。
- 离开期间的收益会在回来时结算。另有成就、怪物图鉴、月度统计图、年度村报、分享图片、存档导入导出，并可作为应用安装、离线游玩。
