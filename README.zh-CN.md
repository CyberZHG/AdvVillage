# 冒险者之村

[English](README.md) | 中文

**在线游玩：** https://cyberzhg.github.io/AdvVillage/

一款致敬开罗游戏的像素风模拟经营游戏。你负责铺路和建造，冒险者、采集者、村民和游客会自己生活，挂机也能一直运转。

- **建设村庄**：住房、商店、饭店、酒馆、洗浴中心、剧场、竞技场等，建筑门口朝向道路；特定建筑相邻可形成组合，提升收入与吸引力。
- **冒险者**：八种职业，自动狩猎、接取讨伐委托、购买装备、锻造武器，还会获得称号、结为搭档、结婚生子。
- **100 种怪物**：分布在各村野外和十处远征地点，另有稀有的闪光个体，以及需要全协会合力讨伐的头目。
- **游客**：观光消费，常客熟悉村子后会送来礼物。
- **四季、天气与节日**：改变风景与客流；随机事件与行商让村子更有生气，且不会打断游戏。
- **评价**：第 16 年结束时评分并解锁下一座村庄（共五座，各有特色），之后可继续游玩。
- 成就、怪物图鉴、年度村报、分享图片、存档导入导出。
- 支持 English、中文、日本語、한국어。
